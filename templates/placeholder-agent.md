# ATRPG 游戏目录

> ⚠️ 本目录尚未完成配置。请使用备团编辑器或手动编辑以下文件来填充内容。

## 目录结构

本目录是一个 ATRPG 游戏上下文目录，文件结构如下：

| 路径 | 用途 |
|------|------|
| `agent.md` | 本文件（目录自描述） |
| `data/world-book.md` | 世界设定（常驻世界观知识，**优先配置**） |
| `data/style-guide.md` | 文风参考 |
| `data/characters/` | 玩家角色 |
| `data/npcs/` | NPC |
| `data/locations/` | 地点 |
| `data/scenes/` | 镜头过场 |
| `data/items/` | 关键道具 |
| `data/story-arcs/` | 故事弧光 |
| `data/state-records/` | 状态记录 |
| `data/terminology/` | 设定术语 |
| `.atrpg/` | 运行时缓存（自动维护，勿手动编辑） |

## 快速开始

1. 编辑 `data/world-book.md`，填写世界观设定
2. （可选）编辑 `data/style-guide.md`，定义文风偏好
3. 启动 ATRPG 服务，即可开始游戏
