# 港口区

## 描写
港口区是这座海岸城市的心脏与暗疮。码头林立，桅杆如林，来自远洋的货物在此吞吐。商人的账房、渔民的棚屋、水手的酒馆、走私者的地下仓库挤在同一片街区里，彼此心照不宣。

主街石板路通向码头，支巷越走越窄、越走越暗。东面是富人货仓区，有守卫巡逻；西面是穷人聚居的「潮汐巷」，治安官不太愿意深入。

## 氛围
- 基调：盐味、鱼腥、焦油、偶尔的香料甜腻。
- 传闻：最近有货物失踪，码头工人议论纷纷，但没人敢明说。

## 子地点
- 港口区大门（port-gate）：正式入口关卡
