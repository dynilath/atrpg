# 港口走私案

## 一句话梗概
玩家卷入港口区失踪货物与走私网络的调查，逐步揭开背后更大的势力。

## 四阶段设计

### 启程
- **故事钩子**：玩家在港口区大门被守卫盘查时，目睹一队工人慌张运走一批无标识货箱；或被某知情者低声求助。
- **引入场景**：港口区大门、潮汐巷。

### 矛盾积累
- 调查展开，发现失踪货物与一个代号「黑潮」的走私组织有关。
- 更大威胁显现：黑潮背后疑似有港口官员庇护。
- 内部矛盾：是否要冒险揭发？是否接受黑潮的招揽？

### 高潮
- **核心挑战**：与黑潮头目的正面对峙，或在官员庇护曝光后面临的抉择——举报 / 沉默 / 借势。
- **关键对峙对象**：黑潮头目 Vorath（待生成 NPC）。

### 新的稳定
- **新平衡**：走私网络被破获或被收编，港口区权力结构重组。
- **劫后收获**：玩家声望提升、获得线人网络、或被某势力盯上（伏笔）。
